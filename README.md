# VELORA — техника для жизни

Учебный многостраничный сайт для КТ 4 «Использование Git при создании многостраничного сайта». Автор: Женя.

VELORA — вымышленная компания с личной электроникой, бытовой техникой и профессиональными решениями. Все модели, характеристики и цены — учебные примеры. Реальная оплата и заказ не предусмотрены.

## Страницы

- `index.html` — главная: продукт, три сценария использования, категории.
- `catalog.html` — 12 моделей в 6 направлениях, поиск, категории, сортировка.
- `product.html?id=one-s` — страница товара, характеристики, выбор цвета у смартфона.
- `about.html` — компания, направления и ответы на вопросы.

## Запуск

Откройте `index.html` в браузере. Для одинакового поведения корзины между страницами рекомендуется локальный сервер:

```sh
node tools/serve.mjs
```

Адрес: http://127.0.0.1:4173. Нужен Node.js 22 или новее, установка пакетов не требуется. Остановка сервера: Ctrl+C.

## Возможности

Адаптивная версия, мобильное меню, клавиатурная навигация, поддержка уменьшенной анимации, поиск и фильтры каталога с URL-параметрами, сортировка по цене, корзина с количеством, удалением и сохранением в localStorage. При недоступном хранилище корзина продолжает работать на текущей странице. Нативный dialog управляет фокусом и закрывается по Escape.

## Git

Локальный репозиторий `.git` входит в папку проекта. Ветка `main` содержит начальный каркас, ветка `КТ` — реализацию. После проверки работа объединяется отдельным merge-коммитом с `main`. Историю можно посмотреть командой:

```sh
git log --graph --oneline --all
```

Имя автора: Женя. Email автора настроен только для этого репозитория.
